# 🎟️ TicketQR — Generate & Scan

All-in-one PWA: generate QR tickets from Google Sheets, share via WhatsApp/Email, and scan them at the door.

## 🚀 Deploy to GitHub Pages (2 min)

1. Create a new repo on GitHub
2. Upload the 3 files: `index.html`, `manifest.json`, `sw.js`
3. Go to **Settings → Pages → Source: main branch** → Save
4. Your app is live at: `https://YOUR-USERNAME.github.io/REPO-NAME/`

## 📱 Install on Phone

Open the link on your phone → **"Add to Home Screen"** → Done!

## Features

- **⚙️ Setup** — Enter your Google Sheet link + event details
- **🎟️ Tickets** — Generate, copy (JPG), download, share via WhatsApp & Email
- **📷 Scanner** — Scan QR codes, verify against database, track scan count
- **📊 Dashboard** — Scan history, attendee list, duplicate detection
